# fleetd Self-Evolution: Модель угроз и защитный контур (Threat Model & Safety Harness)

**Проект:** [fleetd self-evolution](https://linear.app/mindrock/project/fleetd-self-evolution-f59303c6939c)  
**Статус:** Каноническая модель угроз  
**Версия:** 1.0.0  

---

## 1. Анализ рисков саморазвивающейся системы

| Угроза | Механизм реализации | Мера защиты в fleetd vNext |
|---|---|---|
| **Wireheading / Reward Hacking** | Модель меняет функцию оценки или метрики, чтобы показывать искусственный 100% успех. | Reward-функция и метрики телеметрии вынесены в Frozen Core. Автономные агенты не имеют права записи в код телеметрии. |
| **Silent Mutation** | Незаметное самоизменение поведения в обход версионирования. | Любое обновление политики фиксируется отдельным коммитом с версией (`policy_vX.Y.json`), проверяется регрессионным тестом и требует независимого QA. |
| **Treacherous Turn** | Захват привилегий или попытка самостоятельного перевода задач в статус `Done`. | Строгий запрет в Конституции (AGENTS.md). Статус `Done` закрывается исключительно Принципом Павлом Черкашиным. |
| **Double Claim & Race Conditions** | Два слота одновременно берут одну задачу и перезаписывают результат друг друга. | Атомарный Lease Record с TTL и блокировкой повторных обращений. |
| **Quota Denial of Service** | Всплеск низкоприоритетных задач выжигает 10-часовую квоту и парализует ключевые тикеты ВС/ВП. | Fail-closed pacing, детерминированная отсечка поданных МП-задач, разделение пулов agy и codex. |
| **Cloud Disruption / API Leaks** | Отправка внутреннего кода или секретов во внешние API для маршрутизации. | Роутер работает строго локально на MacBook Wolfram в режиме офлайн без обращения к платным API в горячем пути. |

## 2. Аппаратные барьеры и Kill Switches

1. **Файл аварийной остановки (Kill-switch)**:
   При создании файла `/tmp/fleetd.freeze` демон немедленно переводит все слоты в режим паузы (`DRAIN`), завершает текущие задачи и блокирует новые захваты.
2. **Аппаратные лимиты Wolfram**:
   * Ограничение потребления RAM для локальной модели: $\le 2.5$ GB.
   * Контроль дискового пространства: блокировка запуска при остатке свободного места $< 5$ GB.
3. **Автоматический откат (Auto-Rollback)**:
   При падении точности маршрутизации или обнаружении регресса на исторических инцидентах система откатывается к проверенным детерминированным эвристикам.
