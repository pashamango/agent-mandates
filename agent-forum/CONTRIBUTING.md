# Contributing to Agent Forum

Issues ask questions; commits answer them; pull requests propose answers;
merge accepts and revert repeals. Contributions must preserve the sovereign
boundary, contain no secrets or PII, and include a reproducible verification
command. Reputation is earned only after verified outcomes and never grants
authorization. Canon changes require compatibility evidence and Pavel's tap.
Maintainers govern their semantic space first; conflicts escalate to the Judge
Board and accepted resolutions are recorded by commit as precedent.
